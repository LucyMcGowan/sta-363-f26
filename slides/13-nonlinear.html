Polynomial regression

Polynomial regression

\[y_i = \beta_0 + \beta_1x_i + \beta_2x_i^2 + \beta_3x_i^3 + \dots + \beta_dx_i^d + \varepsilon_i\]

Polynomial regression

\[y_i = \beta_0 + \beta_1x_i + {\require{color}\colorbox{#eec8e1}{$\beta_2x_i^2 + \beta_3x_i^3$}} + \dots + \beta_dx_i^d + \varepsilon_i\]

New predictors built from the old one by raising it to a power. The model is still linear in the \(\beta\)s, so least squares fits it exactly as it did before.

Polynomial regression

\[y_i = \beta_0 + \beta_1x_i + \beta_2x_i^2 + \beta_3x_i^3 + \dots + {\require{color}\colorbox{#eec8e1}{$\beta_dx_i^d$}} + \varepsilon_i\]

The degree \(d\). It is unusual to go above 3 or 4, since a high degree polynomials take on strange shapes, especially near the boundary of \(X\).

Reading the fit

  • Read the fitted function \(\hat{f}(x_0)\), since single coefficients are not meaningful
  • More often, read the change between two values \(a\) and \(b\)

\[\small{\hat{f}(b) - \hat{f}(a) = \hat\beta_1(b - a) + \hat\beta_2(b^2 - a^2) + \hat\beta_3(b^3 - a^3) + \hat\beta_4(b^4 - a^4)}\]

How would you pick \(a\) and \(b\)?

With no other information, the 25th and 75th percentiles: 33.75 and 51 for age.

Step functions

Step functions

\[y_i = \beta_0 + \beta_1C_1(x_i) + \beta_2C_2(x_i) + \dots + \beta_KC_K(x_i) + \varepsilon_i\]

Step functions

\[y_i = \beta_0 + \beta_1{\require{color}\colorbox{#eec8e1}{$C_1(x_i)$}} + \beta_2C_2(x_i) + \dots + \beta_KC_K(x_i) + \varepsilon_i\]

Pick cutpoints \(c_1 < c_2 < \dots < c_K\). Then \(C_1(x_i) = I(c_1 \leq x_i < c_2)\) is 1 when \(x_i\) falls in the bin between the first two cutpoints and 0 otherwise. Every \(x_i\) lands in exactly one bin, so at most one \(C_k(x_i)\) is nonzero.

Step functions

\[y_i = {\require{color}\colorbox{#eec8e1}{$\beta_0$}} + \beta_1C_1(x_i) + \beta_2C_2(x_i) + \dots + \beta_KC_K(x_i) + \varepsilon_i\]

\(C_0(x_i) = I(x_i < c_1)\) is left out because it would duplicate the intercept, the same dummy coding as Meeting 7. So \(\beta_0\) is the mean of \(Y\) below \(c_1\), and \(\beta_k\) is how far the mean in bin \(k\) sits from it.

Regression splines

Piecewise polynomials

\[y_i = \begin{cases}\beta_{01} + \beta_{11}x_i + \beta_{21}x_i^2 + \beta_{31}x_i^3 + \varepsilon_i & x_i < c\\ \beta_{02} + \beta_{12}x_i + \beta_{22}x_i^2 + \beta_{32}x_i^3 + \varepsilon_i & x_i \geq c\end{cases}\]

Two cubics, one on each side of a knot at \(c\). What could go wrong at \(c\)?

A degree-\(d\) spline is a piecewise degree-\(d\) polynomial with continuous derivatives up to degree \(d - 1\) at each knot.

Adding constraints

ISLP Figure 7.3. A subset of Wage with a knot at age 50. Unconstrained cubics (8 degrees of freedom), cubics forced to be continuous (7), a cubic spline with continuous first and second derivatives as well (5), and a linear spline.

Linear spline

\[y_i = \beta_0 + \beta_1x_i + \beta_2(x_i - \xi_1)_+ + \dots + \beta_{K+1}(x_i - \xi_K)_+ + \varepsilon_i\]

Linear spline

\[y_i = \beta_0 + \beta_1x_i + \beta_2{\require{color}\colorbox{#eec8e1}{$(x_i - \xi_1)_+$}} + \dots + \beta_{K+1}(x_i - \xi_K)_+ + \varepsilon_i\]

The positive part: \((x_i - \xi_1)_+ = x_i - \xi_1\) when \(x_i > \xi_1\), and 0 otherwise. It is zero up to the knot \(\xi_1\) and rises with slope 1 after it, so it bends the line without breaking it. As basis functions, \(b_1(x) = x\) and \(b_{k+1}(x) = (x - \xi_k)_+\).

Linear spline

\[y_i = \beta_0 + \beta_1x_i + {\require{color}\colorbox{#eec8e1}{$\beta_2$}}(x_i - \xi_1)_+ + \dots + \beta_{K+1}(x_i - \xi_K)_+ + \varepsilon_i\]

The change in slope at \(\xi_1\). Left of the first knot the slope is \(\beta_1\), and between \(\xi_1\) and \(\xi_2\) it is \(\beta_1 + \beta_2\).

Cubic spline

\[\begin{aligned}y_i = \beta_0 &+ \beta_1x_i + \beta_2x_i^2 + \beta_3x_i^3\\ &+ \beta_4(x_i - \xi_1)^3_+ + \dots + \beta_{K+3}(x_i - \xi_K)^3_+ + \varepsilon_i\end{aligned}\]

Cubic spline

\[\begin{aligned}y_i = \beta_0 &+ \beta_1x_i + \beta_2x_i^2 + \beta_3x_i^3\\ &+ \beta_4{\require{color}\colorbox{#eec8e1}{$(x_i - \xi_1)^3_+$}} + \dots + \beta_{K+3}(x_i - \xi_K)^3_+ + \varepsilon_i\end{aligned}\]

A truncated power function, one per knot: \((x_i - \xi_1)^3\) past the knot and 0 before it. Adding it changes only the third derivative at \(\xi_1\), so the fit stays continuous there, with continuous first and second derivatives.

Cubic spline

\[\begin{aligned}y_i = \beta_0 &+ \beta_1x_i + \beta_2x_i^2 + \beta_3x_i^3\\ &+ \beta_4(x_i - \xi_1)^3_+ + \dots + {\require{color}\colorbox{#eec8e1}{$\beta_{K+3}$}}(x_i - \xi_K)^3_+ + \varepsilon_i\end{aligned}\]

An intercept plus \(K + 3\) predictors, so a cubic spline with \(K\) knots uses \(K + 4\) degrees of freedom. With one knot that is the 5 from Figure 7.3.

Natural cubic splines

A natural spline is a regression spline that is also required to be linear beyond the boundary knots, where \(X\) is smaller than the smallest knot or larger than the largest.

Linearity adds two constraints at each boundary knot. With \(K\) interior knots a natural spline uses \(K + 2\) degrees of freedom against \(K + 4\) for a cubic spline, so it can carry two more knots for the same total.

Knot placement

  • Decide on \(K\), then place the knots at uniform quantiles of \(X\)
  • A cubic spline with \(K\) knots uses \(K + 4\) degrees of freedom
  • Choose \(K\) by cross-validation, the same way as \(d\) or \(\lambda\)

A spline gets more flexible by adding knots while the degree stays at 3. A polynomial can only get more flexible by raising its degree.

SplineTransformer

from sklearn.preprocessing import SplineTransformer
from sklearn.model_selection import GridSearchCV, KFold

cv = KFold(n_splits=10, shuffle=True, random_state=363)
spline = make_pipeline(
    SplineTransformer(degree=3, knots="quantile", extrapolation="linear"),
    LinearRegression(),
)
grid = GridSearchCV(spline, {"splinetransformer__n_knots": range(2, 12)},
                    cv=cv, scoring="neg_mean_squared_error").fit(X, y)
grid.best_params_["splinetransformer__n_knots"], round(float(-grid.best_score_), 1)
1
SplineTransformer replaces a column with a cubic spline basis. It uses
B-splines rather than truncated power functions, a different basis for the same set of curves, and one that stays well conditioned.
2
knots="quantile" places the knots at quantiles of age instead of evenly
across its range. extrapolation="linear" continues each end of the fit as a straight line past the boundary knots, the tail behavior of a natural spline, without the natural spline’s savings in degrees of freedom.
3
n_knots counts the two boundary knots at the smallest and largest age,
so n_knots=4 means two interior knots and \(K + 4 = 6\) degrees of freedom. GridSearchCV tries 2 through 11 on the same ten folds. 
(4, 1595.8)

The degree-4 polynomial scores 1596.6 on the same folds. Which would you use?

Generalized additive models

Generalized additive models

\[y_i = \beta_0 + f_1(x_{i1}) + f_2(x_{i2}) + \dots + f_p(x_{ip}) + \varepsilon_i\]

Generalized additive models

\[y_i = \beta_0 + {\require{color}\colorbox{#eec8e1}{$f_1(x_{i1})$}} + f_2(x_{i2}) + \dots + f_p(x_{ip}) + \varepsilon_i\]

Each linear term \(\beta_jx_{ij}\) is replaced by a function of that predictor alone: a polynomial, a step function, or a spline. The model is additive because the \(p\) contributions are added up, so each \(f_j\) can be read while holding the other predictors fixed.

A GAM for Wage

ISLP Figure 7.11. A GAM for wage with a natural spline in year (four degrees of freedom), a natural spline in age (five), and a separate constant for each level of education. Each panel holds the other two predictors fixed.

A GAM in scikit-learn

from sklearn.compose import ColumnTransformer
from sklearn.preprocessing import OneHotEncoder
from sklearn.model_selection import cross_val_score

basis = ColumnTransformer([
    ("year", SplineTransformer(n_knots=3, include_bias=False), ["year"]),
    ("age", SplineTransformer(n_knots=4, include_bias=False), ["age"]),
    ("education", OneHotEncoder(drop="first"), ["education"]),
])
gam = make_pipeline(basis, LinearRegression())
X3 = Wage[["year", "age", "education"]]
round(float(-cross_val_score(gam, X3, y, cv=cv, scoring="neg_mean_squared_error").mean()), 1)
1
ColumnTransformer applies a different transformer to each named group of
columns and stacks the results side by side into one design matrix.
2
SplineTransformer(n_knots=3, include_bias=False) gives year a cubic
spline with one interior knot. include_bias=False drops one basis column, since the full B-spline basis for a predictor sums to 1 and would duplicate the intercept.
3
OneHotEncoder(drop="first") turns the five levels of education into
four 0/1 columns, a step function for a qualitative predictor.
4
make_pipeline(basis, LinearRegression()) fits every column by least
squares at once. A GAM built from splines is one big regression on basis columns. 
1244.3

The spline in age alone scored 1595.8. Where did the improvement come from?

Pros and cons

  • A nonlinear \(f_j\) for each \(X_j\), without trying transformations one by one
  • Each \(f_j\) can be read holding the other predictors fixed
  • The smoothness of each \(f_j\) is summarized by its degrees of freedom

The model is additive, so an interaction such as age by education has to be added by hand. Chapter 8, starting Friday, covers models that find interactions without being told.
