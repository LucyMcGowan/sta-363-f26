Least squares, ridge, and the lasso all predict a number.

The Default outcome is Yes or No. What have we used for that so far?

Classification

Classification

The response \(Y\) takes values in an unordered set \(\mathcal{C}\). The task is a function \(C(X)\) returning a member of \(\mathcal{C}\), and usually the probability of each member is what we actually want.

  • email in {spam, not spam}
  • default in {Yes, No}
  • diagnosis in {stroke, overdose, seizure}

Coding the outcome

\[Y = \begin{cases} 0 & \text{if No} \\ 1 & \text{if Yes}\end{cases}\]

\(E[Y \mid X = x] = \Pr(Y = 1 \mid X = x)\), so a least squares fit of \(Y\) on \(X\) is estimating a probability.

So why not fit a line and call anything above 0.5 a default?

The logistic model

The logistic function

\[p(X) = \frac{e^{\beta_0 + \beta_1X}}{1 + e^{\beta_0 + \beta_1X}}\]

The logistic function

\[p(X) = \frac{{\require{color}\colorbox{#eec8e1}{$e^{\beta_0 + \beta_1X}$}}}{1 + e^{\beta_0 + \beta_1X}}\]

The same linear function least squares used, exponentiated, so it is positive for every value of \(\beta_0\), \(\beta_1\) and \(X\), however far the linear part runs.

The logistic function

\[p(X) = \frac{e^{\beta_0 + \beta_1X}}{{\require{color}\colorbox{#eec8e1}{$1 + e^{\beta_0 + \beta_1X}$}}}\]

The denominator is the numerator plus one, so it is always the larger of the two. The ratio therefore lands strictly between 0 and 1, whatever the coefficients are.

Rearranging

\[\log\left(\frac{p(X)}{1 - p(X)}\right) = \beta_0 + \beta_1X\]

\(p(X) / (1 - p(X))\) are the odds, and its log is the log odds or logit. The model is linear in the log odds.

Odds

A 60% chance of rain: \(p = 0.6\), \(1 - p = 0.4\), odds \(= 0.6/0.4 = 1.5\), or 3 to 2.

  • Probability lives on \([0, 1]\)
  • Odds live on \([0, \infty)\)
  • Log odds live on the whole real line, which is where a linear function lives

Transforming back and forth

probability odds log odds
\(\pi\) \(\frac{\pi}{1 - \pi}\) \(\log\left(\frac{\pi}{1-\pi}\right) = \ell\)
log odds odds probability
\(\ell\) \(e^{\ell}\) \(\frac{e^{\ell}}{1 + e^{\ell}} = \pi\)

The model gives you \(\ell\). Which row do you read to get a probability?

Reading a coefficient

A one unit increase in \(X\) adds \(\beta_1\) to the log odds, and multiplies the odds by \(e^{\beta_1}\).

That is a statement about odds, not about probability. Why can we not say a one unit increase in \(X\) adds a fixed amount to \(p(X)\)?

Odds ratios

TMS Placebo
Pain-free after two hours 39 22
Still in pain 61 78

Odds of being pain-free: \(39/61 = 0.639\) with TMS, \(22/78 = 0.282\) with placebo. The odds ratio is \(0.639 / 0.282 = 2.27\).

A logistic regression of pain-free status on treatment would return which number as \(e^{\hat\beta_1}\)?

Maximum likelihood

\[\ell(\beta_0, \beta_1) = \prod_{i: y_i = 1} p(x_i) \prod_{i: y_i = 0}\left(1 - p(x_i)\right)\]

Maximum likelihood

\[\ell(\beta_0, \beta_1) = {\require{color}\colorbox{#eec8e1}{$\prod_{i: y_i = 1} p(x_i)$}} \prod_{i: y_i = 0}\left(1 - p(x_i)\right)\]

For every observation that did default, the model’s own predicted probability of defaulting. We want these large.

Maximum likelihood

\[\ell(\beta_0, \beta_1) = \prod_{i: y_i = 1} p(x_i) {\require{color}\colorbox{#eec8e1}{$\prod_{i: y_i = 0}\left(1 - p(x_i)\right)$}}\]

For every observation that did not, the model’s predicted probability of not defaulting. We want these large too. The whole product is the probability the fitted model assigns to the exact pattern of ones and zeros observed, and \(\beta_0\) and \(\beta_1\) are chosen to make it as large as it goes. This plays the role RSS played for a numeric response.

DATA = "https://raw.githubusercontent.com/LucyMcGowan/sta-363-f26/main/data/"

LogisticRegression fits the model by maximum likelihood, through the same
.fit and .predict interface every other estimator uses.
2
Comparing the default column to "Yes" and calling .astype(int) gives

3
C=1e10 makes the penalty scikit-learn applies by default effectively
zero, so these are the unpenalized maximum likelihood estimates that match ISLP Table 4.1. max_iter=10000 gives the solver room to converge.
4
intercept_ is \(\hat\beta_0\) and coef_[0][0] is \(\hat\beta_1\), the
change in log odds of default per dollar of balance. 
(-10.6513, 0.005499)

Predicting a probability

\[\hat{p}(X) = \frac{e^{-10.6513 + 0.0055 \times 1000}}{1 + e^{-10.6513 + 0.0055 \times 1000}} = 0.006\]

\[\hat{p}(X) = \frac{e^{-10.6513 + 0.0055 \times 2000}}{1 + e^{-10.6513 + 0.0055 \times 2000}} = 0.586\]

Balance doubled and the probability went up by a factor of a hundred. Which part of the model does that?

Confounding

ISLP Figure 4.3. Left: default rate against balance for students in orange and non-students in blue, with the overall rates as dashed lines. Right: balance by student status.

Two true statements

  • Students default more often than non-students, because they carry more debt
  • At any given balance, a student defaults less often than a non-student

Which one a bank needs depends on what it knows. Without a balance, the marginal rate. With a balance in hand, the conditional one.

More than two classes

\[\Pr(Y = k \mid X) = \frac{e^{\beta_{0k} + \beta_{1k}X_1 + \dots + \beta_{pk}X_p}}{\sum_{l=1}^{K}e^{\beta_{0l} + \beta_{1l}X_1 + \dots + \beta_{pl}X_p}}\]

One linear function per class, exponentiated and divided by their total, so the \(K\) probabilities sum to 1. LogisticRegression does this for you when y has more than two values.

The threshold is a choice

The fitted model produces probabilities. Turning one into a label needs a cutoff, and 0.5 is a default rather than a result.

The penalty is on by default

from sklearn.preprocessing import StandardScaler
from sklearn.pipeline import make_pipeline
from sklearn.model_selection import cross_val_score, StratifiedKFold

cv = StratifiedKFold(n_splits=10, shuffle=True, random_state=363)
rows = []
for C in [0.001, 0.01, 1, 1e10]:
    m = make_pipeline(StandardScaler(), LogisticRegression(C=C, max_iter=10000))
    auc = cross_val_score(m, X3, y, cv=cv, scoring="roc_auc").mean()
    rows.append({"C": C, "cv_auc": auc,
                 "coef_norm": float(np.linalg.norm(m.fit(X3, y)[-1].coef_[0]))})
pd.DataFrame(rows).round(4)
1
StratifiedKFold keeps the 3.33% default rate in every fold, which matters
because a plain KFold could hand a fold very few defaults.
2
C is one over the penalty strength, so small C is a heavy penalty and
1e10 is effectively none.
3
roc_auc measures how well the model ranks customers by risk rather than
how many labels it gets right. Friday defines it.

What C is doing

LogisticRegression() with no arguments is ridge-penalized logistic regression. That is why StandardScaler belongs in front of it, for the same reason it belonged in front of Ridge in Meeting 9.

The AUC barely moves between C = 1 and C = 1e10. What does that say about whether the penalty is doing anything here?
