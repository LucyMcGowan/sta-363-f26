The Bayes classifier

The Bayes classifier

Assign \(x_0\) to the class \(j\) with the largest \[\Pr(Y = j \mid X = x_0)\]

Why can we never use this on real data?

Bayes decision boundary

ISLP Figure 2.13. One hundred observations in each of two classes. The purple dashed line is the Bayes decision boundary. The Bayes error rate is 0.133.

Bayes error rate

\[1 - E\left[\max_j \Pr(Y = j \mid X)\right]\]

Bayes error rate

\[1 - E\left[{\require{color}\colorbox{#eec8e1}{$\max_j \Pr(Y = j \mid X)$}}\right]\]

The largest class probability at a given \(X\): how sure the Bayes classifier can ever be there.

Bayes error rate

\[1 - {\require{color}\colorbox{#eec8e1}{$E\left[\max_j \Pr(Y = j \mid X)\right]$}}\]

Average that best-possible confidence over every value of \(X\). One minus it is the lowest test error any classifier can reach.

Distance

Distance

\[d(x_0, x_i) = \sqrt{\sum_{j=1}^{p}\left(x_{0j} - x_{ij}\right)^2}\]

Distance

\[d(x_0, x_i) = \sqrt{\sum_{j=1}^{p}\left({\require{color}\colorbox{#eec8e1}{$x_{0j} - x_{ij}$}}\right)^2}\]

How far apart \(x_0\) and a training point \(x_i\) are on predictor \(j\) alone.

Distance

\[d(x_0, x_i) = \sqrt{{\require{color}\colorbox{#eec8e1}{$\sum_{j=1}^{p}$}}\left(x_{0j} - x_{ij}\right)^2}\]

Sum the squared differences across all \(p\) predictors, then the square root out front turns that sum into an ordinary Euclidean distance. This is what “closest” means below.

K-nearest neighbors

To classify \(x_0\), find the \(K\) closest training points and take a vote.

K-nearest neighbors

\[\Pr(Y = j \mid X = x_0) \approx \frac{1}{K}\sum_{i \in \mathcal{N}_0} I(y_i = j)\]

K-nearest neighbors

\[\Pr(Y = j \mid X = x_0) \approx \frac{1}{K}\sum_{i \in {\require{color}\colorbox{#eec8e1}{$\mathcal{N}_0$}}} I(y_i = j)\]

The \(K\) training points closest to \(x_0\) by the distance above.

K-nearest neighbors

\[\Pr(Y = j \mid X = x_0) \approx {\require{color}\colorbox{#eec8e1}{$\frac{1}{K}$}}\sum_{i \in \mathcal{N}_0} I(y_i = j)\]

Divide by \(K\) so the vote is a proportion rather than a raw count.

K-nearest neighbors

\[\Pr(Y = j \mid X = x_0) \approx \frac{1}{K}\sum_{i \in \mathcal{N}_0} {\require{color}\colorbox{#eec8e1}{$I(y_i = j)$}}\]

1 if neighbor \(i\) belongs to class \(j\), 0 if it does not.

KNN in scikit-learn

from sklearn.neighbors import KNeighborsClassifier
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from sklearn.pipeline import make_pipeline

X = Default[["balance", "income"]]
y = (Default["default"] == "Yes").astype(int)
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=363, stratify=y
)

ks = [1, 3, 5, 10, 25, 50, 100, 200]
train_err, test_err = [], []
for k in ks:
    m = make_pipeline(StandardScaler(), KNeighborsClassifier(n_neighbors=k))
    m.fit(X_train, y_train)
    train_err.append(1 - m.score(X_train, y_train))
    test_err.append(1 - m.score(X_test, y_test))
1
KNeighborsClassifier is scikit-learn’s K-nearest-neighbors classifier;
the number of neighbors K is set later as n_neighbors.
2
X selects two columns, "balance" and "income", as the predictors.
3
y compares Default["default"] to the string "Yes" element-wise,
producing True/False, then .astype(int) converts that to 1 (default) or 0 (no default).
4
test_size=0.3 holds out 30% of rows for testing; random_state=363
fixes the shuffle; stratify=y forces both the training and test split to keep the same proportion of defaults as the full data, since defaults are rare.
5
ks lists the values of K to try, from most flexible (K=1) to most
rigid (K=200).
6
make_pipeline chains StandardScaler(), which centers and scales
balance and income to comparable ranges, with KNeighborsClassifier (n_neighbors=k); scaling matters here because KNN measures distance directly, so an unscaled column with a larger range would dominate.
7
m.score(X_train, y_train) returns training accuracy, so 1 - that
value is the training error rate, appended to train_err.

Curse of dimensionality

  • KNN works well when \(p\) is small and \(n\) is large
  • As \(p\) grows, the nearest neighbors stop being near
  • With \(p = 20\), capturing 10% of the data needs 80% of every range

Beyond the error rate

.score() and the error rate both ask a classifier to commit to a single label per observation. .predict_proba() asks it to rank instead.

probs = best.predict_proba(X_test)[:, 1]
top100 = np.argsort(-probs)[:100]

A bank can only call 100 customers today. Which 100 would you pick: the 100 predicted “default,” or the 100 ranked most likely to default?
