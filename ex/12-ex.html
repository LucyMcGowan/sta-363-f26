Application exercise 12: Thresholds, ROC, and imbalance

STA 363 | Meeting 12 | October 2

The logistic model from Wednesday got 97.3% of Default right. A rule that predicts “no” for everybody gets 96.7%. Accuracy has almost no room to distinguish the two, so today’s measures look at the errors separately by class.

Setup

import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
DATA = "https://raw.githubusercontent.com/LucyMcGowan/sta-363-f26/main/data/"
from sklearn.linear_model import LogisticRegression
from sklearn.neighbors import KNeighborsClassifier
from sklearn.preprocessing import StandardScaler
from sklearn.pipeline import make_pipeline
from sklearn.model_selection import (
    train_test_split, cross_validate, StratifiedKFold
)
from sklearn.metrics import confusion_matrix, roc_curve, roc_auc_score

Default = pd.read_csv(DATA + "Default.csv")
y = (Default["default"] == "Yes").astype(int)
X = pd.DataFrame({
    "balance": Default["balance"],
    "income": Default["income"] / 1000,
    "student": (Default["student"] == "Yes").astype(float),
})

X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=363, stratify=y
)
model = make_pipeline(StandardScaler(), LogisticRegression(max_iter=10000))
model.fit(X_train, y_train)
probs = model.predict_proba(X_test)[:, 1]
float(round(y_test.mean(), 4))
0.0333

Part 1: The confusion matrix

cm = confusion_matrix(y_test, (probs > 0.5).astype(int))
pd.DataFrame(
    cm,
    index=["truly no default", "truly default"],
    columns=["predicted no", "predicted yes"],
)
predicted no predicted yes
truly no default 2888 12
truly default 67 33
  1. Label each of the four cells TN, FP, FN, TP.
  2. Compute sensitivity, specificity, and precision from those four numbers by hand. Sensitivity is TP over the number who truly defaulted, specificity is TN over the number who truly did not, precision is TP over the number predicted to default.
  3. The overall error rate is small and the sensitivity is not. Which one would a credit card company be paid to care about, and why?
tn, fp, fn, tp = cm.ravel()
tp / (tp + fn), tn / (tn + fp), tp / (tp + fp)

Part 2: The threshold is yours to set

Nothing in the fitted model says 0.5. That number came from predict, and you can pick another.

rows = []
for t in [0.5, 0.3, 0.2, 0.1, 0.05]:
    tn, fp, fn, tp = confusion_matrix(y_test, (probs > t).astype(int)).ravel()
    rows.append({
        "threshold": t,
        "flagged": int(tp + fp),
        "sensitivity": tp / (tp + fn),
        "specificity": tn / (tn + fp),
        "error_rate": (fp + fn) / len(y_test),
    })

pd.DataFrame(rows).round(4)
threshold flagged sensitivity specificity error_rate
0 0.50 45 0.33 0.9959 0.0263
1 0.30 98 0.53 0.9845 0.0307
2 0.20 159 0.63 0.9669 0.0443
3 0.10 247 0.73 0.9400 0.0670
4 0.05 373 0.86 0.9010 0.1003 
grid = np.linspace(0.01, 0.9, 120)
overall, among_default, among_no = [], [], []
for t in grid:
    tn, fp, fn, tp = confusion_matrix(y_test, (probs > t).astype(int)).ravel()
    overall.append((fp + fn) / len(y_test))
    among_default.append(fn / (fn + tp))
    among_no.append(fp / (fp + tn))

fig, ax = plt.subplots(figsize=(6.5, 3.4))
ax.plot(grid, overall, color="#595959", label="overall")
ax.plot(grid, among_default, color="#d5008f", ls="--", label="among defaulters")
ax.plot(grid, among_no, color="#e8a33d", ls=":", label="among non-defaulters")
ax.set_xlabel("threshold")
ax.set_ylabel("error rate")
ax.legend(fontsize=7)
plt.show()
  1. Which threshold minimizes the overall error rate? Is that a coincidence, given what the Bayes classifier does?
  2. Moving from 0.5 to 0.1 raises sensitivity from 0.33 to 0.73 and the overall error rate from 0.026 to 0.067. Describe a bank for which that trade is worth making, and one for which it is not.
  3. The three curves cannot all be pushed down at once. What information, not in this data set, would you need in order to choose a threshold defensibly?

Part 3: ROC and AUC

A ROC curve plots the true positive rate against the false positive rate at every threshold at once, so no single cutoff has to be chosen to draw it.

knn = make_pipeline(StandardScaler(), KNeighborsClassifier(n_neighbors=25))
knn.fit(X_train, y_train)
probs_knn = knn.predict_proba(X_test)[:, 1]

fig, ax = plt.subplots(figsize=(4.6, 4.2))
for p_hat, name, color in [
    (probs, "logistic", "#d5008f"),
    (probs_knn, "25-nearest neighbors", "#007c86"),
]:
    fpr, tpr, _ = roc_curve(y_test, p_hat)
    ax.plot(fpr, tpr, color=color, label=f"{name}: {roc_auc_score(y_test, p_hat):.3f}")
ax.plot([0, 1], [0, 1], color="#595959", ls=":", lw=1)
ax.set_xlabel("false positive rate")
ax.set_ylabel("true positive rate")
ax.legend(fontsize=7, loc="lower right")
plt.show()
  1. The true positive rate is one of the three measures from Part 1 under a different name, and the false positive rate is one minus another. Which is which?
  2. Mark roughly where the threshold 0.5 sits on the logistic curve, and where 0.1 sits. Which direction along the curve does lowering the threshold move you?
  3. What does the dotted diagonal represent, and what AUC does it have?
  4. Logistic regression beats 25-nearest neighbors by about 0.04 of AUC. Both had nearly identical accuracy in Meeting 11. Which comparison tells you more?

Part 4: A rare outcome

Caravan has 5,822 customers and 86 predictors, and 348 of them bought caravan insurance.

Caravan = pd.read_csv(DATA + "Caravan.csv")
y_car = (Caravan["Purchase"] == "Yes").astype(int)
X_car = Caravan.drop(columns=["Purchase"])

cv = StratifiedKFold(n_splits=5, shuffle=True, random_state=363)
scoring = ["accuracy", "roc_auc", "recall", "precision"]

rows = []
for name, weight in [("plain", None), ("class_weight balanced", "balanced")]:
    m = make_pipeline(
        StandardScaler(),
        LogisticRegression(max_iter=5000, class_weight=weight),
    )
    r = cross_validate(m, X_car, y_car, cv=cv, scoring=scoring)
    rows.append({"model": name, **{s: r[f"test_{s}"].mean() for s in scoring}})

pd.DataFrame(rows).round(4)
model accuracy roc_auc recall precision
0 plain 0.9370 0.7313 0.0087 0.0900
1 class_weight balanced 0.6991 0.7301 0.6466 0.1213
  1. What is the accuracy of a rule that predicts “no purchase” for all 5,822 customers? Compare it to the plain model’s accuracy.
  2. The plain model’s recall is close to zero. Say, in terms of what the fitting procedure is minimizing, why a rare class gets ignored.
  3. class_weight="balanced" trades accuracy for recall. Which of the four scores barely moved between the two rows, and what does that tell you about what class_weight actually changed?

class_weight="balanced" reweights each observation by the inverse of its class frequency, so the 348 buyers count for as much in total as the 5,474 non-buyers. That changes which coefficients minimize the loss, while leaving the order the model puts customers in largely alone.

Part 5: Scoring changes the winner

rows = []
for k in [1, 3, 5, 10, 25, 50, 100, 200]:
    m = make_pipeline(StandardScaler(), KNeighborsClassifier(n_neighbors=k))
    r = cross_validate(m, X_car, y_car, cv=cv, scoring=["accuracy", "roc_auc"])
    rows.append({
        "K": k,
        "accuracy": r["test_accuracy"].mean(),
        "roc_auc": r["test_roc_auc"].mean(),
    })

sweep = pd.DataFrame(rows)
sweep.round(4)

  1. Which K does scoring="accuracy" choose? Which does scoring="roc_auc" choose?
  2. Look at the accuracy column from K = 10 down to K = 200. Why does it stop changing, and what number has it stopped at?
  3. A GridSearchCV on this data with the default scoring would report a tuned model. What would be wrong with it?

Every model this semester has been tuned against a single number. Choosing that number is a modeling decision, and on imbalanced data accuracy is usually the wrong one.

precision_recall_curve from sklearn.metrics plots precision against recall instead of TPR against FPR. Draw one for Caravan alongside the ROC curve.

The ROC curve for Caravan looks respectable and the precision-recall curve looks poor. Both describe the same fitted model. Which denominator differs between the two, and which curve would you show a client deciding whether to mail 500 brochures?
