Application exercise 15: Classification trees

STA 363

A classification tree is grown by the same recursive binary splitting as a regression tree. Each leaf predicts the most commonly occurring class among its training observations, and each split is chosen to lower the Gini index or the entropy rather than the RSS. Part 1 works by hand with one split from ISLP Figure 8.6. Parts 2 and 3 fit regression and classification trees side by side on Carseats.

Setup

import numpy as np
import pandas as pd

Part 1: Node purity by hand

Near the bottom right of the unpruned tree in ISLP Figure 8.6, 20 patients reach the split RestECG < 1, and 16 of them have heart disease. The split sends 11 patients left, 7 of them with heart disease, and 9 patients right, all 9 with heart disease. Both leaves predict Yes.

  1. With two classes and \(\hat{p}\) the proportion Yes, show that the Gini index is \(G = 2\hat{p}(1 - \hat{p})\).
  2. On paper, fill in the table, using the natural log for the entropy \(D\) and taking \(0 \log 0 = 0\).
  3. After the split, weight each leaf’s value by its share of the 20 patients and add. Which of \(E\), \(G\) and \(D\) go down?
  4. One new patient lands in the left leaf and another in the right. Both are predicted Yes. Which prediction would you trust more, and which measures reflect that?

purity takes the class counts in a node and returns all three measures. Check your table against it.

def purity(counts):
    p = np.array(counts) / sum(counts)
    return {"E": 1 - p.max(), "G": (p * (1 - p)).sum(),
            "D": (-p[p > 0] * np.log(p[p > 0])).sum()}


nodes = {"before the split": [16, 4], "left leaf": [7, 4], "right leaf": [9, 0]}
pd.DataFrame({name: purity(c) for name, c in nodes.items()}).T.round(3)

Part 2: Regression tree versus classification tree

Part 3: Pruning, and trees versus linear models

Pruning works the same way as for a regression tree. On a classifier, cost_complexity_pruning_path measures fit with the Gini index, the criterion used to grow the tree, and scoring="accuracy" then chooses among those subtrees by cross-validated accuracy, which is one minus the classification error rate.

big = DecisionTreeClassifier(min_samples_leaf=5, random_state=363).fit(X, High)
path = big.cost_complexity_pruning_path(X, High)
search = GridSearchCV(
    DecisionTreeClassifier(min_samples_leaf=5, random_state=363),
    {"ccp_alpha": path.ccp_alphas},
    cv=cv, scoring="accuracy",
).fit(X, High)
pruned = search.best_estimator_

int(big.get_n_leaves()), int(pruned.get_n_leaves()), round(float(search.best_score_), 3)
(38, 11, 0.728)
models = {"majority class": DummyClassifier(), "unpruned tree": big,
          "pruned tree": pruned,
          "logistic regression": make_pipeline(StandardScaler(),
                                               LogisticRegression(penalty=None, max_iter=10000))}
pd.Series({
    name: cross_val_score(m, X, High, cv=cv, scoring="accuracy").mean()

  1. How many leaves does \(T_0\) have, and how many does cross-validation keep?
  2. Rank the four models by cross-validated accuracy. How much does the pruned tree gain over predicting the majority class for every store?
  3. On Hitters in application exercise 14, both trees beat least squares. On Carseats, logistic regression wins. Using ISLP Section 8.1.3, what does that suggest about how High depends on the predictors?
  4. Which model would you hand to a store manager who wants to understand when sales run high, and which would you use to predict it?

A classification tree is grown and pruned the same way as a regression tree. Each leaf predicts its most common class, and splits are chosen by the Gini index or the entropy, which reward purer nodes even when the predicted class stays the same.
