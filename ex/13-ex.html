Application exercise 13: Polynomials, splines, and GAMs

STA 363

Wage has wage and demographic data for 3,000 male workers in the Mid-Atlantic region. Plotted against age, wage rises, levels off, and falls again, a shape that a straight line cannot follow. Each method below builds new columns from age and hands them to least squares.

Setup

import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
DATA = "https://raw.githubusercontent.com/LucyMcGowan/sta-363-f26/main/data/"
from sklearn.linear_model import LinearRegression
from sklearn.preprocessing import (
    PolynomialFeatures, StandardScaler, SplineTransformer, OneHotEncoder
)
from sklearn.pipeline import make_pipeline
from sklearn.compose import ColumnTransformer
from sklearn.model_selection import cross_val_score, KFold
from sklearn.inspection import PartialDependenceDisplay

Wage = pd.read_csv(DATA + "Wage.csv")
X_age = Wage[["age"]]
y = Wage["wage"]
cv = KFold(n_splits=10, shuffle=True, random_state=363)

The scaler is there for numerical reasons. Raw powers of age run up to \(80^4\), about 41 million, and are close to collinear. They are the same polynomial, so any difference comes from the solver losing precision on nearly collinear columns.

Part 2: Step functions

step_basis cuts age at the cutpoints given and returns one 0/1 column per bin, leaving out the first bin so the intercept stands in for it.

def step_basis(age, cuts):
    bins = pd.cut(age, [-np.inf, *cuts, np.inf], right=False)
    C = pd.get_dummies(bins, drop_first=True).astype(float)
    C.columns = C.columns.astype(str)
    return C


new_ages = pd.Series([25, 34, 36, 64, 66])
rows = {}
for cuts in [[35, 65], [30, 65]]:
    step = LinearRegression().fit(step_basis(Wage["age"], cuts), y)
    rows[f"cutpoints {cuts[0]} and {cuts[1]}"] = step.predict(step_basis(new_ages, cuts))

Part 4: A cubic spline by hand

A cubic spline with the same two knots uses \(b_1(x) = x\), \(b_2(x) = x^2\), \(b_3(x) = x^3\), \(b_4(x) = (x - 35)^3_+\) and \(b_5(x) = (x - 65)^3_+\).

  1. Compute \(b_4(x)\) and \(b_5(x)\) by hand for the eight values of \(x\) in Part 3. Most of them are zero.
  2. Write out the model you would fit with this cubic spline. How many coefficients does it estimate, and how does that match \(K + 4\)?

SplineTransformer builds a cubic spline from B-splines instead. Given the same interior knots, and the range of the data as its boundary knots, it fits the same model with different columns.

x = np.array([4, 15, 25, 37, 49, 66, 70, 80])
y_toy = np.array([7.89, 30.07, 49.92, 69.97, 69.81, 66.89, 54.85, 24.62])


def cubic_basis(x):
    return pd.DataFrame({
        "b1": x,
        "b2": x**2,
        "b3": x**3,
        "b4": np.maximum(x - 35, 0) ** 3,
        "b5": np.maximum(x - 65, 0) ** 3,
    })


by_hand = LinearRegression().fit(cubic_basis(x), y_toy)

knots = np.array([[4], [35], [65], [80]])
bspline = make_pipeline(
    SplineTransformer(degree=3, knots=knots, extrapolation="continue"),
    LinearRegression(),
)
bspline.fit(x.reshape(-1, 1), y_toy)

pd.DataFrame({
    "x": x,
    "truncated power": by_hand.predict(cubic_basis(x)),
    "B-spline": bspline.predict(x.reshape(-1, 1)),
}).round(3)

  2. Roughly what does the cubic spline predict at \(x = -100\) and at \(x = 100\)? Which part of the fitted curve is being carried out that far?
  3. extrapolation="linear" changes how the fit is drawn past 4 and 80 and leaves the fit inside the data alone. A natural cubic spline makes linearity past the boundary knots part of the fit. How many degrees of freedom does that save here, and what could they be spent on?

Part 5: A GAM for Wage

A generalized additive model gives each predictor its own function and adds them up. Built from splines and dummy variables, it is one least squares fit on a wide design matrix. year and age are converted to floats, since PartialDependenceDisplay refuses integer columns.

X3 = Wage[["year", "age", "education"]].astype({"year": float, "age": float})

gam = make_pipeline(
    ColumnTransformer([
        ("year", SplineTransformer(n_knots=3, include_bias=False), ["year"]),
        ("age", SplineTransformer(n_knots=4, include_bias=False), ["age"]),
        ("education", OneHotEncoder(drop="first"), ["education"]),
    ]),
    LinearRegression(),
)
linear = make_pipeline(
    ColumnTransformer(
        [("education", OneHotEncoder(drop="first"), ["education"])],
        remainder="passthrough",
    ),
    LinearRegression(),
)

MSE = "neg_mean_squared_error"
pd.Series({
    "polynomial in age": -cross_val_score(poly4, X_age, y, cv=cv, scoring=MSE).mean(),
    "linear in year, age, education": -cross_val_score(linear, X3, y, cv=cv, scoring=MSE).mean(),
    "GAM": -cross_val_score(gam, X3, y, cv=cv, scoring=MSE).mean(),
}).round(1)
polynomial in age                 1596.6

fig, axes = plt.subplots(1, 3, figsize=(10, 3.4))

  1. The GAM and the linear model use the same three predictors. What is the only difference between them, and how much does it lower the CV MSE?
  2. Read the age panel. Holding year and education fixed, describe how predicted wage changes with age, and compare its shape to the polynomial in Part 1.
  3. ISLP suggests the rise in the year panel may be inflation. Does that panel look close enough to a straight line that a single linear term would do? Describe how you would check with cross-validation.
  4. The age curve has the same shape at every level of education. Describe a pattern in wages that this model cannot represent.

Polynomials, step functions, and splines are all basis expansions: new columns built from an old one and fit by least squares. A GAM stacks one expansion per predictor.

If you finish early

The GAM above fixed n_knots for age at 4. Tune it with GridSearchCV over the values 2 to 10, using the parameter name "columntransformer__age__n_knots".

Which value does cross-validation choose, and how much does the CV MSE move across the range? ISLP suggests fixing the degrees of freedom at about four for every term in a GAM instead of tuning each one. Does your result support that?
