Application exercise 9: Ridge regression

STA 363 | Meeting 9 | September 23

Credit has 400 customers, a credit card balance, and a handful of predictors, two of which measure almost the same thing.

Setup

import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
DATA = "https://raw.githubusercontent.com/LucyMcGowan/sta-363-f26/main/data/"
from sklearn.linear_model import LinearRegression, Ridge
from sklearn.preprocessing import StandardScaler
from sklearn.pipeline import make_pipeline
from sklearn.model_selection import cross_val_score, KFold, GridSearchCV

Credit = pd.read_csv(DATA + "Credit.csv")
cols = ["Income", "Limit", "Rating", "Cards", "Age", "Education"]

X = Credit[cols].copy()
X["Student"] = (Credit["Student"] == "Yes").astype(float)
y = Credit["Balance"]

  1. Each of the 200 resamples draws 30 rows with replacement from the same 30 rows, so nothing about the population changed. Which coefficient moves the most across those resamples, relative to its own size?

Part 2: Ridge by hand

Ridge minimizes RSS plus \(\lambda\sum_j \beta_j^2\), which gives \(\hat\beta^R = (\mathbf{X}^T\mathbf{X} + \lambda\mathbf{I})^{-1}\mathbf{X}^T\mathbf{y}\). The predictors are standardized first and the response is centered, so no intercept is needed and no coefficient is penalized for its units.

Z = StandardScaler().fit_transform(X)
y_centered = y - y.mean()

lambdas = np.logspace(-2, 5, 80)
paths = np.array([
    np.linalg.solve(Z.T @ Z + lam * np.eye(Z.shape[1]), Z.T @ y_centered)
    for lam in lambdas
])

fig, ax = plt.subplots(figsize=(6.5, 3.6))
for j, name in enumerate(X.columns):
    ax.plot(lambdas, paths[:, j], label=name)
ax.set_xscale("log")
ax.set_xlabel("lambda")
ax.set_ylabel("standardized coefficient")
ax.legend(fontsize=6, ncol=2)
plt.show()
  1. Read off the far left of the plot. What are those values, and why?
  2. Read off the far right. What model is ridge fitting there?
  3. Rating rises before it falls. Ridge shrinks the coefficient vector as a whole, so how can one coefficient grow?

Set lam to a very large number and compute np.linalg.solve(Z.T @ Z + lam * np.eye(7), Z.T @ y_centered) directly. Then try the same with lam = 0 after dropping Limit and adding a column equal to Rating * 2. Which one fails, and what does the error message say?

Part 3: Scale changes the answer

Limit is recorded in dollars. Recording it in thousands of dollars is the same data.

X_k = X.copy()
X_k["Limit"] = X_k["Limit"] / 1000


def train_mse(model, data):
    return float(np.mean((y - model.fit(data, y).predict(data)) ** 2))


pd.DataFrame({
    "dollars": [
        train_mse(LinearRegression(), X),
        train_mse(Ridge(alpha=100), X),
        train_mse(make_pipeline(StandardScaler(), Ridge(alpha=100)), X),
    ],
    "thousands": [
        train_mse(LinearRegression(), X_k),
        train_mse(Ridge(alpha=100), X_k),

  2. Ridge without a scaler gives a different training MSE, and its Limit coefficient did not scale by 1000. Which term in the ridge criterion is responsible?

Part 4: When ridge earns its keep

Fifty observations, forty-five predictors, and a true coefficient that is nonzero for every single one of them.

rng = np.random.default_rng(363)
n_sim, p_sim = 50, 45
X_sim = pd.DataFrame(
    rng.normal(size=(n_sim, p_sim)), columns=[f"x{j}" for j in range(p_sim)]
)
beta = rng.normal(0, 1, p_sim)
y_sim = X_sim.values @ beta + rng.normal(0, 2, n_sim)

cv = KFold(n_splits=10, shuffle=True, random_state=363)
ols_mse = -cross_val_score(
    LinearRegression(), X_sim, y_sim, cv=cv, scoring="neg_mean_squared_error"
).mean()

alphas = np.logspace(-2, 4, 40)
grid = GridSearchCV(
    make_pipeline(StandardScaler(), Ridge()),
    {"ridge__alpha": alphas},
    cv=cv,
    scoring="neg_mean_squared_error",
).fit(X_sim, y_sim)

round(float(ols_mse), 1), round(grid.best_params_["ridge__alpha"], 2), round(-grid.best_score_, 1)
(3116.0, np.float64(2.03), np.float64(19.6))
  1. Report the two cross-validated MSEs. By what factor does ridge beat least squares?
  2. Every one of the 45 predictors has a nonzero true coefficient, so least squares is fitting the right model. Why does it still lose this badly?
  3. Compare both numbers to \(\text{Var}(\varepsilon) = 4\), the irreducible error. How close does ridge get?

Part 5: The trade-off, one plot

curve, norms = [], []
for a in alphas:
    m = make_pipeline(StandardScaler(), Ridge(alpha=a))
    curve.append(-cross_val_score(
        m, X_sim, y_sim, cv=cv, scoring="neg_mean_squared_error"
    ).mean())
    norms.append(np.linalg.norm(m.fit(X_sim, y_sim)[-1].coef_))

fig, axes = plt.subplots(1, 2, figsize=(9, 3.2))
axes[0].plot(alphas, curve, color="#d5008f")
axes[0].set_xscale("log")
axes[0].set_yscale("log")
axes[0].set_xlabel("alpha")
axes[0].set_ylabel("10-fold CV MSE")
axes[1].plot(alphas, norms, color="#007c86")
axes[1].set_xscale("log")
axes[1].set_xlabel("alpha")
axes[1].set_ylabel("l2 norm of coefficients")
plt.tight_layout()
plt.show()
  1. The left panel is U-shaped, like the test MSE curves from Meeting 3. Which side of the minimum is variance dominated, and which side is bias dominated?
  2. In Meeting 3 the horizontal axis was flexibility, increasing to the right. Here it is alpha. Which direction is more flexible now?
  3. The right panel falls to zero. What does a coefficient vector of length zero predict for every observation?
