Application exercise 10: Lasso and elastic net

STA 363 | Meeting 10 | September 25

Ridge shrank all nineteen Hitters coefficients and kept all nineteen predictors. The lasso shrinks and drops.

Setup

import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
DATA = "https://raw.githubusercontent.com/LucyMcGowan/sta-363-f26/main/data/"
from sklearn.linear_model import LinearRegression, Ridge, Lasso, ElasticNet
from sklearn.preprocessing import StandardScaler
from sklearn.pipeline import make_pipeline
from sklearn.model_selection import cross_val_score, KFold, GridSearchCV

Hitters = pd.read_csv(DATA + "Hitters.csv")
Hitters = Hitters.dropna(subset=["Salary"]).reset_index(drop=True)

X = pd.get_dummies(Hitters.drop(columns=["Salary"]), drop_first=True).astype(float)
y = Hitters["Salary"]
cv = KFold(n_splits=10, shuffle=True, random_state=363)
X.shape
(263, 19)

Part 1: Coefficient paths

Z = StandardScaler().fit_transform(X)
alphas = np.logspace(-1, 3, 60)

paths = np.array([Lasso(alpha=a, max_iter=200000).fit(Z, y).coef_ for a in alphas])
n_nonzero = (paths != 0).sum(axis=1)

fig, axes = plt.subplots(1, 2, figsize=(9.5, 3.3))
for j in range(X.shape[1]):
    axes[0].plot(alphas, paths[:, j], lw=1.2)
axes[0].set_xscale("log")
axes[0].set_xlabel("alpha")
axes[0].set_ylabel("standardized coefficient")
axes[1].plot(alphas, n_nonzero, color="#d5008f")
axes[1].set_xscale("log")
axes[1].set_xlabel("alpha")
axes[1].set_ylabel("nonzero coefficients")
plt.tight_layout()
plt.show()
  1. Compare the left panel to the ridge paths from Friday. What does a lasso path do that a ridge path never does?
  2. The right panel is a staircase down to zero. At roughly what alpha does the model become the null model?
  3. Ridge would give a right panel that is a flat line at 19. Say why, in terms of the two penalties.

Part 2: Choosing alpha

rows = []
for a in alphas:
    m = make_pipeline(StandardScaler(), Lasso(alpha=a, max_iter=200000))
    s = -cross_val_score(m, X, y, cv=cv, scoring="neg_mean_squared_error")
    rows.append({
        "alpha": a,
        "cv_mse": s.mean(),
        "cv_se": s.std(ddof=1) / np.sqrt(10),
        "nonzero": int((m.fit(X, y)[-1].coef_ != 0).sum()),
    })

lasso_cv = pd.DataFrame(rows)
best = lasso_cv["cv_mse"].idxmin()

  2. Apply the one standard error rule from Meeting 8: take the largest alpha whose cv_mse is within one cv_se of the minimum. How many predictors survive now?
  3. Name them. Compare that set to the forward stepwise path from Meeting 8. How much do the two procedures agree?

The one standard error rule wants the simplest model that is still competitive. For the lasso, simpler means a larger penalty, so take the maximum alpha that clears the threshold rather than the minimum.

Part 4: When each one wins

Two simulations, both with 50 observations and 45 predictors. The first has 45 nonzero true coefficients. The second has 2.

def simulate(n_nonzero, n=50, p=45, magnitude=1.0, noise=4.0, seed=363):
    rng = np.random.default_rng(seed)
    Xs = pd.DataFrame(rng.normal(size=(n, p)), columns=[f"x{j}" for j in range(p)])
    beta = np.zeros(p)
    beta[:n_nonzero] = rng.normal(0, magnitude, n_nonzero)
    ys = Xs.values @ beta + rng.normal(0, noise, n)
    return Xs, ys


def best_of(model_name, model, param, Xs, ys):
    g = GridSearchCV(
        make_pipeline(StandardScaler(), model),
        {f"{model_name}__alpha": param},
        cv=KFold(10, shuffle=True, random_state=363),
        scoring="neg_mean_squared_error",
    ).fit(Xs, ys)
    return -g.best_score_, int((g.best_estimator_[-1].coef_ != 0).sum())


rows = []
for label, args in [("dense: 45 nonzero", (45, 50, 45, 1.0)),
                    ("sparse: 2 nonzero", (2, 50, 45, 3.0))]:
    Xs, ys = simulate(*args)
    lm, ln = best_of("lasso", Lasso(max_iter=200000), np.logspace(-2, 2, 40), Xs, ys)
    rm, rn = best_of("ridge", Ridge(), np.logspace(-2, 4, 40), Xs, ys)
    rows.append({"truth": label, "lasso_mse": lm, "lasso_used": ln,
                 "ridge_mse": rm, "ridge_used": rn})

pd.DataFrame(rows).round(1)
truth lasso_mse lasso_used ridge_mse ridge_used
0 dense: 45 nonzero 48.8 10 45.5 45
1 sparse: 2 nonzero 22.8 2 31.4 45
  1. Which method wins in each row? Connect the answer to the shape of the true \(\beta\) in each simulation.
  2. In the sparse row, how many predictors did the lasso keep, out of 45? Is that the right number?
  3. On real data you cannot see \(\beta\). Given that, how would you decide between ridge and the lasso?

Part 5: Elastic net

Elastic net carries both penalties at once. l1_ratio says how much of the total penalty is the lasso part: 1.0 is pure lasso, 0.0 is pure ridge.

enet = GridSearchCV(
    make_pipeline(StandardScaler(), ElasticNet(max_iter=200000)),
    {
        "elasticnet__alpha": np.logspace(-1, 3, 30),
        "elasticnet__l1_ratio": [0.1, 0.3, 0.5, 0.7, 0.9, 1.0],
    },
    cv=cv, scoring="neg_mean_squared_error",
).fit(X, y)

results = pd.DataFrame(enet.cv_results_)
best_by_ratio = -results.pivot_table(
    index="param_elasticnet__l1_ratio", values="mean_test_score", aggfunc="max"
)
enet.best_params_, best_by_ratio.round(0)

Least squares cannot be fit at all now. Both ridge and the lasso still run. The lasso can select at most \(n\) predictors when \(p > n\). Why would that limit ever be a problem?
