Application exercise 11: Logistic regression

STA 363 | Meeting 11 | September 30

Default records 10,000 credit card customers, 333 of whom defaulted. KNN handled this data back in Meeting 4 by taking a vote among neighbors. Logistic regression handles it with a model.

Setup

import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
DATA = "https://raw.githubusercontent.com/LucyMcGowan/sta-363-f26/main/data/"
from sklearn.linear_model import LinearRegression, LogisticRegression
from sklearn.neighbors import KNeighborsClassifier
from sklearn.preprocessing import StandardScaler
from sklearn.pipeline import make_pipeline
from sklearn.model_selection import cross_val_score, StratifiedKFold

Default = pd.read_csv(DATA + "Default.csv")
y = (Default["default"] == "Yes").astype(int)
float(round(y.mean(), 4))
0.0333

C=1e10 below turns scikit-learn’s penalty off, so the coefficients match the ones in ISLP. Part 5 comes back to why the penalty is there at all. Part 5 also scores with roc_auc, which gets its definition on Friday: for now, read it as how well the model ranks customers by risk, where 1.0 is a perfect ranking and 0.5 is chance.

Part 1: Why not a straight line

straight = LinearRegression().fit(Default[["balance"]], y)
logistic = LogisticRegression(C=1e10, max_iter=10000).fit(Default[["balance"]], y)

grid = pd.DataFrame({"balance": np.linspace(-500, 3000, 200)})

fig, axes = plt.subplots(1, 2, figsize=(9, 3.2), sharey=True)
for ax, curve, name in [
    (axes[0], straight.predict(grid), "linear regression"),
    (axes[1], logistic.predict_proba(grid)[:, 1], "logistic regression"),
]:
    ax.axhline(0, color="#595959", lw=0.6, ls=":")
    ax.axhline(1, color="#595959", lw=0.6, ls=":")
    ax.plot(grid["balance"], curve, color="#d5008f", lw=2)
    ax.scatter(Default["balance"], y, marker="|", color="#e8a33d", alpha=0.3)
    ax.set_title(name)
    ax.set_xlabel("balance")
plt.tight_layout()
plt.show()
  1. Find a balance value where the left panel returns something that cannot be a probability. What value does it return there?
  2. The right panel never leaves the interval from 0 to 1. Which part of the logistic function guarantees that?
  3. Between about 1400 and 2000 the two curves nearly coincide. If you only ever needed predictions in that range, would the distinction matter?

Part 5: The penalty scikit-learn adds by default

LogisticRegression() with no arguments applies a ridge penalty, controlled by C, which is one over the strength of the penalty. Small C means a large penalty.

cv = StratifiedKFold(n_splits=10, shuffle=True, random_state=363)

rows = []
for C in [0.0001, 0.001, 0.01, 1, 100, 1e10]:
    m = make_pipeline(StandardScaler(), LogisticRegression(C=C, max_iter=10000))
    auc = cross_val_score(m, X3, y, cv=cv, scoring="roc_auc").mean()
    coefs = m.fit(X3, y)[-1].coef_[0]
    rows.append({"C": C, "cv_auc": auc, "coef_norm": float(np.linalg.norm(coefs))})

pd.DataFrame(rows).round(4)

  1. As C shrinks, what happens to coef_norm? Which method from last week does that reproduce?
