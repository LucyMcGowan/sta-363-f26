Application exercise 2: Training error misleads

STA 363 | Meeting 2 | August 28

Setup

import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from sklearn.model_selection import train_test_split

Part 3: Training MSE versus test MSE

We fit a spline to horsepower, and increase the degrees of freedom (df) to make the fit more flexible.

dfs = range(4, 21, 2)
train_mse, test_mse = [], []

for df in dfs:
    model = make_pipeline(SplineTransformer(degree=3, n_knots=df - 2), LinearRegression())
    model.fit(X_train, y_train)
    train_mse.append(mean_squared_error(y_train, model.predict(X_train)))
    test_mse.append(mean_squared_error(y_test, model.predict(X_test)))
pd.DataFrame({"df": dfs, "train": train_mse, "test": test_mse}).round(2)
