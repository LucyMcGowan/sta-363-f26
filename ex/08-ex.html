Application exercise 8: Choosing a subset

STA 363 | Meeting 8 | September 18

Hitters records 1986 performance and 1987 salary for 322 Major League Baseball players. Salary is missing for 59 of them, so those rows come out first.

Setup

import itertools
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
DATA = "https://raw.githubusercontent.com/LucyMcGowan/sta-363-f26/main/data/"
from sklearn.linear_model import LinearRegression
from sklearn.model_selection import cross_val_score, KFold

Hitters = pd.read_csv(DATA + "Hitters.csv")
Hitters = Hitters.dropna(subset=["Salary"]).reset_index(drop=True)

X = pd.get_dummies(Hitters.drop(columns=["Salary"]), drop_first=True).astype(float)
y = Hitters["Salary"]
n, p = X.shape

Part 1: How large is the search

  1. Best subset selection fits every model that uses some subset of the p predictors. How many models is that, for the p you just printed?
  2. At one thousand model fits per second, how long would that take?
  3. A classmate proposes fitting all of them and keeping the one with the smallest RSS. Name the problem with that plan that has nothing to do with computing time.
2 ** p

Part 2: Best subset on eight predictors

Restrict the pool to eight predictors so best subset is actually runnable.

pool = ["AtBat", "Hits", "Walks", "Years", "CRuns", "CRBI", "CWalks", "PutOuts"]
tss = float(((y - y.mean()) ** 2).sum())


def rss(cols):
    f = LinearRegression().fit(X[cols], y)
    return float(((y - f.predict(X[cols])) ** 2).sum())


rows = []
for k in range(1, len(pool) + 1):
    best = min(itertools.combinations(pool, k), key=lambda c: rss(list(c)))
    r = rss(list(best))
    rows.append({"k": k, "rss": r, "r2": 1 - r / tss, "vars": ", ".join(best)})

Part 3: Forward stepwise on all of them

At each step the loop adds whichever remaining predictor lowers RSS the most, and never reconsiders an earlier choice.

chosen, remaining, path = [], list(X.columns), []

while remaining:
    best = min(remaining, key=lambda c: rss(chosen + [c]))
    chosen = chosen + [best]
    remaining.remove(best)
    path.append({"d": len(chosen), "added": best, "rss": rss(chosen)})

Part 4: Four ways to pick d

Each of these adjusts training RSS for model size, so that models with different numbers of predictors can be compared.

sigma2 = rss(list(X.columns)) / (n - p - 1)
cv = KFold(n_splits=10, shuffle=True, random_state=363)

rows = []
for step in path:
    d = step["d"]
    cols = [s["added"] for s in path[:d]]
    r = step["rss"]
    scores = -cross_val_score(
        LinearRegression(), X[cols], y, cv=cv, scoring="neg_mean_squared_error"
    )
    rows.append({
        "d": d,
        "Cp": (r + 2 * d * sigma2) / n,
        "BIC": (r + np.log(n) * d * sigma2) / n,
        "adj_r2": 1 - (r / (n - d - 1)) / (tss / (n - 1)),
        "cv_mse": scores.mean(),
        "cv_se": scores.std(ddof=1) / np.sqrt(10),
    })

crit = pd.DataFrame(rows)

best_row = crit["cv_mse"].idxmin()
threshold = crit["cv_mse"][best_row] + crit["cv_se"][best_row]
smallest = int(crit.loc[crit["cv_mse"] <= threshold, "d"].min())
