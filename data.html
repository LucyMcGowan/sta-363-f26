Course Data

Every data set we use is served from the course repository, so you never install anything to get at it. All of them come from the textbook.

How to read one

import pandas as pd

DATA = "https://raw.githubusercontent.com/LucyMcGowan/sta-363-f26/main/data/"
Default = pd.read_csv(DATA + "Default.csv")

Three percent of customers default. Knowing that before you fit anything is what stops you being impressed by a model that gets 97% accuracy by always saying no.

Where these came from

All ten ship with the ISLP package that accompanies the textbook. They are exported to CSV here so that nothing has to be installed. The script that does it is data/export-data.py in the course repository.

If you want the book’s own labs, which use from ISLP import load_data, install the package and everything on this site still works:

%pip install ISLP

Colab will ask you to restart the runtime afterward. That is expected, and it is the reason we do not require it.

Data from James, G., Witten, D., Hastie, T., Tibshirani, R., and Taylor, J. (2023). An Introduction to Statistical Learning with Applications in Python. Springer.
