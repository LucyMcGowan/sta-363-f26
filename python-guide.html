Model fitting

from sklearn.linear_model import LinearRegression

X = Auto[["horsepower", "weight"]]   # predictors, always a data frame
y = Auto["mpg"]                      # response, always a single column

model = LinearRegression()           # 1. choose
model.fit(X, y)                      # 2. fit
model.predict(X.head(3))             # 3. predict
array([19.18811123, 16.43741528, 18.63605667])
model.score(X, y)                    # 4. score
0.7063752737298348

Swap LinearRegression() for KNeighborsRegressor(5) or RandomForestRegressor() and the other three lines stay as they are.

Pipelines

A pipeline attaches preprocessing to a model so they always occur together.

from sklearn.preprocessing import StandardScaler
from sklearn.neighbors import KNeighborsRegressor
from sklearn.pipeline import make_pipeline

pipe = make_pipeline(StandardScaler(), KNeighborsRegressor(10))
pipe.fit(X, y)
pipe.score(X, y)
0.7790841201261199

Errors you will see

NameError: name 'X' is not defined You did not run the cell that created X, or the runtime restarted. Run your cells from the top.

KeyError: 'mpg' That column does not exist. Check Auto.columns for the exact spelling. Column names are case sensitive.

ValueError: Expected 2D array, got 1D array instead scikit-learn wants predictors as a data frame. Use Auto[["horsepower"]] with two sets of brackets, not Auto["horsepower"].

SettingWithCopyWarning You modified a slice of a data frame. Add .copy() when you subset something you intend to change.
